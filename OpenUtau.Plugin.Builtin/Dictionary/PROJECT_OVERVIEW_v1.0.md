## 1. Project Objective and Ultimate Goal
The primary objective of this project is to engineer a highly stable, flawless, and comprehensive plugin suite for OpenUtau. It aims to bridge multiple languages and automate tedious vocal tuning tasks, transforming raw inputs into natural, human-like singing with zero structural conflicts.

## 2. Core Missions
2.1 Multilingual Phonemizer Integration
- To seamlessly parse and map lyrics across Thai, English, Japanese, and other languages without relying heavily on external dictionary constraints.
- To ensure the C# backend (`DictBuilder.cs`, `ThaiVCCVPhonemizer`) dynamically handles True and False consonant clusters perfectly.

2.2 Advanced Vocal Tuning Macro
- To automatically apply pitch bends, vibrato, and dynamic expression curves.
- To analyze note lengths and contexts to generate smooth, natural transitions tailored to the selected voicebank.

## 3. System Architecture & Standards
3.1 Code Robustness
- Every line of code must be strictly typed, well-documented, and fail-safe.
- Background compilation tasks and automated deployments must execute with 0 errors and 0 warnings.

3.2 UI and Output Standards
- Dual-language support (Thai/English) gracefully integrated into the OpenUtau UI.
- All system execution files (e.g., Batch files) must remain entirely in English to guarantee encoding stability across all Windows environments.
