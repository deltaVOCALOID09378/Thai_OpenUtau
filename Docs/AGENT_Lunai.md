## 🔴 NEW DIRECTIVES (อัปเดตล่าสุดจากท่านเดลต้า)
AI Agent ต้องยึดถือและปฏิบัติตามกฎ 7 ข้อนี้อย่างเคร่งครัดในการพัฒนา Thai OpenUtau:

1. **Bug Fix & UI Font Optimization:**
   - แก้ไขบั๊กเรื่องโน้ตพักเสียง (Rest Notes / R) ให้ทำงานสมบูรณ์
   - Optimize โค้ดภายในให้เป็นระเบียบและอ่านง่าย
   - อัปเกรดการแสดงผลฟอนต์ภาษาไทย (Leelawadee UI) ให้มีขนาดพอดี สวยงาม หากมีของซ้ำให้ยุบรวม หากไม่มีให้จัดหามาเติมให้ครบ

2. **Custom Consonant Pitch Shapes:**
   - สร้างรูปทรงกราฟ Pitch แบบใหม่ หรือเปลี่ยนค่าตัวเลขของเสียงพยัญชนะ ให้สามารถ "กำหนดความกว้างพื้นที่ขั้นต่ำแบบกำหนดเองได้ตามประเภทของพยัญชนะ"
   - รองรับการลากคลุมแถบจากขวาไปซ้ายเพื่อระบุค่า (ยิ่งกว้างยิ่งชัด) และต้องครอบคลุมถึงพยัญชนะที่มีลักษณะเสียงแบบฉับพลันด้วย

3. **Voicebank Library Sorting & Syncing:**
   - หน้าต่างแสดงคลังเสียง (Voicebank) จะต้องจัดเรียงตามลำดับดังนี้: `ภาษา (Language)` -> `เอนจิน (Engine)` -> `ระบบหน่วยเสียง (Phoneme System)`
   - แสดงผลเฉพาะระบบที่คลังเสียงนั้นๆ รองรับ และอัปเดตข้อมูลการทำงานให้ตรงกันทั้งหมด

4. **Thai Phonemizer Zero-Defect Audit (@Thai):**
   - ตรวจสอบความถูกต้องของการแปลงคำอ่านเนื้อเพลงเป็นหน่วยเสียงภาษาไทย (Thai Phonemes)
   - หากพบส่วนที่ไม่ถูกต้องหรือตกหล่น ให้จัดทำรายงานสรุป และ **แก้ไขให้ถูกต้อง 100% จนกว่าจะสามารถร้องเพลงออกมาได้เหมือนคนจริงเป๊ะๆ**

5. **Oto.ini Options & Consonant Organizer:**
   - สร้างปุ่ม "ออปชั่น" สำหรับจัดระเบียบพื้นที่ของเสียงพยัญชนะให้สอดคล้องกับประเภทของเสียงในการออกแบบชุดหน่วยเสียง
   - **กฎเหล็กเรื่องความปลอดภัย:** ทุกครั้งที่มีการแก้ไขและกดปิดหน้าต่างนี้ ระบบ **จะต้องทำการเซฟและสร้างไฟล์สำรอง (Backup) `oto.ini` อีกชุดหนึ่งเสมอ** เพื่อความเสถียรและความปลอดภัยของข้อมูลคลังเสียง

6. **Auto Pitch Writer (by Canon) Integration & C++ Reverse Engineering:**
   - แก้ไขให้โปรแกรมหลักสามารถทำงานร่วมกับ `AutoPitchwriter.exe` ได้อย่างราบรื่น
   - **สร้างไฟล์ C++** สำหรับแกะ/เชื่อมต่อไฟล์ .exe นี้ และแยกเก็บไว้เฉพาะเจาะจง เพื่อปูทางสำหรับการพัฒนาและปรับปรุงในอนาคต

7. **Universal UI Translation Audit:**
   - ตรวจสอบและแปลเนื้อหา UI ในทุกๆ ภาษา
   - ห้ามละเลยคำศัพท์ใดๆ ต้องแปลให้ครบถ้วนและแสดงผลได้อย่างถูกต้อง
